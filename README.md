# Supermarket Sales Performance Analysis

## Project Overview
This project delivers an interactive Power BI dashboard analyzing supermarket sales transactions to uncover key revenue drivers, product category profitability, customer purchasing behaviors, and regional performance trends

## Key Performance Indicators (KPIs) & Insights
- **Total Revenue & Profit:** Evaluated overall sales performance, profit margins, and transaction volumes.
- **Product Category Analysis:** Identified top-performing product lines (e.g., Electronics, Groceries, Home Appliances) and low-margin items.
- **Customer Segmentation:** Analyzed buying patterns across different customer types (Member vs. Normal).
- **Temporal Trends:** Examined peak sales hours, days of the week, and seasonal spikes.

## Tools & Technologies Used
- **Microsoft Power BI:** Data modeling, DAX measures, and interactive dashboard design.
- **Data Visualization:** Custom charts and KPI cards.
